# @knowman/mcp

A stdio MCP server that lets an MCP client search, ask, save and read items in a KnowMan account.

## Tools

| Tool | Purpose |
|---|---|
| `kb_search` | Search saved items in Inbox, Knowledge Base and Archive without bodies; results carry trust. |
| `kb_ask` | Ask a question over the Knowledge Base or one item; returns an answer with citations. |
| `kb_get_item` | Read content and metadata for one item. |
| `kb_save` | Save a URL to Inbox or Knowledge Base. |
| `kb_recent` | List recently saved items. |
| `kb_memories` | List saved memories such as claims, decisions and playbooks; read-only. |

## Install

`npx -y @knowman/mcp` runs the server on demand. `npm install -g @knowman/mcp` installs the `knowman-mcp` command.

Requires Node.js 22 or newer.

## Get a key

Sign in at https://app.knowman.io, create an API key in settings, and set it as `KNOWMAN_API_KEY`. Never commit the key.

## Configuration

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "knowman": {
      "command": "npx",
      "args": ["-y", "@knowman/mcp"],
      "env": {
        "KNOWMAN_API_KEY": "<your-key>"
      }
    }
  }
}
```

Claude Code:

```bash
claude mcp add knowman --env KNOWMAN_API_KEY=<your-key> -- npx -y @knowman/mcp
```

Cursor (`~/.cursor/mcp.json`, or `.cursor/mcp.json` in a project): use the same `mcpServers` JSON as the Claude Desktop example above.

Prefer signing in with the browser instead of pasting a key? Install the package globally (`npm install -g @knowman/mcp`) and run `knowman login`. The saved credential is shared with `knowman-mcp`, so the `env` block is not needed. Run `knowman status` to check it.

This server speaks stdio, so it runs on your own machine. It is not a hosted or remote MCP endpoint, so clients that only accept remote servers (for example ChatGPT connectors or claude.ai on the web) cannot use it yet.
